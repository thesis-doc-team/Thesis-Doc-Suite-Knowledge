# 免费试用、权益、任务与版本规则

状态：[C] 机制已确认；[V] 具体额度、价格、时间与实现状态待测。

## 初期商业机制
- 免费体验 + 付费的**单项目完整服务包**。
- 免费可上传分析、核对事实，进行**受限制的生成**，但已生成的每页应能完整预览；未获导出权益者的下载需要后端阻断。
- 技术文档是流程前置，可考虑“技术文档 + 一份 Word”的体验组合；这只是候选，不是免费额度定案。
- 付费项目包使用**全项目共享生成/修订任务池**，不对每类文书单独分配，也不拆成生成池与修订池。
- 一次成功标准生成或修订扣一次任务额度；系统故障、超时/失败与系统重试不扣；预览不扣。
- 同一已获授权版本重复下载不重复扣；新版本导出的权益规则须通过产品与技术核对。
- 价格、额度数字及项目期限待真实 API/文书成本验证；**365 天只用于内部测试配置，不作为对外服务期**。

## 必须独立设计的权限
- 生成任务权限 `can_generate`：当前是否允许启动生成/修订。
- 预览权限 `can_preview`：已生成内容应可完整逐页浏览，受用户归属限制。
- 导出权限 `can_export(version_id)`：该具体版本是否能下载，服务端判定。
- 下载记录 `export_grant`：已获得的版本授权不因重试下载重复收费。
- 全部额度变动保持数据库事务性/幂等性，防止并发重复扣费、失败误扣、用户越权下载。

## 社交分享换下载额度：未获最终批准 [V]
- 曾讨论“真实分享一次赠一次导出，单个未付费项目最多两次”。
- Web Share API 触发分享菜单**不等于可证明用户已真实分享**；微信等平台对诱导分享存在规则风险。
- 不得把截图私聊或传播私人项目链接作为任务；试点阶段可使用管理员发放演示导出权替代。
- 若后续实施，应审查平台规则、核验可行性及反作弊，并经用户单独确认。

## 权益验收用例
1. 免费用户已完成生成且可预览全部页，但未经授权下载得到服务端拒绝。
2. 伪造文件 URL、版本 ID、跨账户查询均无法越权。
3. 并发提交两个任务，额度不会负数或重复扣。
4. 模型失败、渲染失败、任务超时、系统自动重试均不会误扣。
5. 成功任务只扣一次；同版本重复下载不重复扣。
6. 服务包到期、删除、退款、恢复中的规则明确且可回溯。
7. 管理员手动补偿/发放额度需要权限与审计记录。
