# 待验证事项与咨询记录

> 初始状态均为**未验证**，不是要求项目现在一次完成所有长期目标。

## 上线阻断类
| ID | 问题 | 下一步动作 | 证据标准 |
|---|---|---|---|
| V-01 | 主体选择：个人/个体户/公司哪种能匹配实际自营服务？ | 提出真实业务说明，咨询注册地市场监管/通信管局 | 正式法规或主管答复 |
| V-02 | 是否需要增值电信业务经营许可证？ | 咨询拟备案属地通信管理局 | 业务定性依据与适用类别 |
| V-03 | ICP 备案材料、主体、接入地域及公安备案 | 咨询云商与属地，整理材料 | 备案号/期限/回执 |
| V-04 | 自身生成式 AI 备案/地方应用登记 | 核对模型备案、问属地网信 | 官方答复/办理凭证 |
| V-05 | DOCX 显式/隐式生成标识如何保持官方模板？ | 依据标识规则和实际 DOCX 样本试验 | 文件原件、元数据与格式比对 |
| V-06 | 模型 API 是否境外转发、用于训练、保留多久？ | 与实际服务商核对合约和数据流 | 官方条款/确认函 |
| V-07 | 真实用户资料与代码的收集/删除/委托 | 建立字段与文件处理台账、隐私政策草案 | 端到端删除/权限测试 |
| V-08 | 生产安全与等保具体适用情形 | 定级分析、询公安网安/专业机构 | 定级与适用路径 |
| V-09 | Linux 可否替代 Windows COM 高保真预览？ | 五类真实模板生成/渲染回归 | Word/WPS 与页预览结果 |
| V-10 | 最新代码完整长流程、容器、下载权、并发额度安全 | 代码审查、集成测试、故障注入 | commit、日志、样例、结果 |

## 不得擅自解决的空白
学校具体所在地、云服务商、运营者姓名与登记信息、支付产品审核状态、具体模型合规编号、真实 API 数据流、产品价格和用户服务期限。全部保持待定，不能让 AI 补成“看起来完整”的假信息。
